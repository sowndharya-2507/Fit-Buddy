# Fit-Buddy 🏋️ - AI Fitness Plan Generator

AI Fitness Plan Generator using Gemini Models. Fit-Buddy creates personalized workout and diet plans based on your fitness goals, age, and body type.

![Python](https://img.shields.io/badge/Python-3.10-blue)
![Gemini AI](https://img.shields.io/badge/AI-Gemini%20API-orange)
![License](https://img.shields.io/badge/License-MIT-green)

## 🚀 Features
- **Personalized AI Plans:** Generates workout plan using Google Gemini AI based on user profile
- **Diet Recommendation:** AI-based Indian diet chart for weight loss / weight gain / muscle gain
- **BMI & BMR Calculator:** Calculates health metrics automatically
- **Goal Based:** Supports Weight Loss, Muscle Gain, Stay Fit, Weight Gain
- **User-friendly UI:** Simple and clean interface built with Streamlit

## 🛠️ Tech Stack
- **AI:** Google Gemini 1.5 Flash API
- **Frontend:** Streamlit
- **Backend:** Python
- **Tools:** Git, GitHub, dotenv
